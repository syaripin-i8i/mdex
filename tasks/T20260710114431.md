# Task: Establish golden relevance and latency evaluation

Create an independent, deterministic evaluation for the existing quality fixture before considering additional discovery features.

## Acceptance criteria

- Keep a manually curated, exhaustive relevance judgment set separate from ranker implementation and scan inputs.
- Report macro Recall@k, Precision@k, MRR, and per-operation results for `context`, `find`, `first`, and `related`.
- Report retrieval latency p50/p95 separately from index construction.
- Compare quality against committed minimums and baseline values without allowing silent degradation.
- Keep latency comparison non-flaky: report it by default and allow enforcement only with a relative plus absolute guardrail in a pinned environment.
- Document the evaluation method, maintenance workflow, and exact commands.
- Verify the evaluator, baseline comparison, and main-index exclusion with automated tests.

## Out of scope

- Ranker changes made to fit the gold set.
- Adoption of the deferred Discovery Lane proposals.
- Treating this deliberately small fixture as evidence of broad production efficacy.

## Results

- Added ten manual, exhaustive cases over the independent six-document fixture: two `context`, four `find`, two `first`, and two `related` cases.
- Added aggregate, operation, and case-level baseline comparisons with 45 always-reported quality observations and strict finite/range validation.
- Added retrieval-only p50/p95 timing with warmup, report-only default comparison, and optional relative-plus-absolute enforcement for pinned environments.
- Propagated the validated scan scoring/synonym configuration through quality, warmup, and timed context calls; normalized text line endings in corpus identity.

## Verification

- Evaluation passes with Recall@3 `1.0`, Precision@3 `0.633333`, MRR `1.0`, and zero quality regressions.
- Repeated rankings and quality metrics are deterministic; latency remains within the committed guardrail.
- The complete test suite, evaluation tests, and main-index exclusion checks pass.
